# edge-collection-extension
一款替代 Edge 浏览器原生集锦功能的本地化扩展插件，支持离线数据存储与网站备注。A local extension plugin that replaces the native Collections feature of the Edge browser, supporting offline data storage and website notes.
项目简介：解决 Edge 原生集锦无法使用的问题,开发了此插件用来将集锦保存在本地。
核心功能：“网页收集”、“添加备注”等功能点。
安装指南：下载本项目的 .zip 压缩包并解压。打开 Edge 浏览器，进入扩展管理页面 (edge://extensions/)。开启左侧的开发人员模式。点击加载解压的扩展，选择刚才解压的文件夹。安装完成后需要将插件驻留在状态栏，第一次打开插件时候需要选择保存数据的文件夹
隐私声明：数据仅保存在本地，不会上传至任何第三方服务器。

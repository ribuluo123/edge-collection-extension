# edge-collection-extension

一款替代 Edge 浏览器原生集锦功能的本地化扩展插件，支持离线数据存储与网站备注。
A local extension plugin that replaces the native Collections feature of the Edge browser, supporting offline data storage and website notes.

## 📌 项目简介
为解决 Edge 原生集锦功能无法正常使用的问题，开发了此插件。本插件完美替代原有集锦，并将所有收集的数据安全地保存在您的本地设备中。

## ✨ 核心功能
* **网页收集**：一键保存当前浏览的网页。
* **添加备注**：支持对收集的网站添加个性化备注信息。
* **本地存储**：数据完全离线化，摆脱云端同步的网络限制。

## 🛠️ 安装指南
由于插件尚未上架微软官方扩展商店，请按照以下步骤进行本地加载：
1. 下载本项目 Releases 页面中的 `.zip` 压缩包并解压到一个固定文件夹。
2. 打开 Edge 浏览器，在地址栏输入并进入扩展管理页面 `edge://extensions/`。
3. 在页面左侧（或左下角）开启 **“开发人员模式”**。
4. 点击顶部的 **“加载解压的扩展”** 按钮，选择您刚才解压的文件夹。
5. **重要提示**：安装完成后，建议将插件固定在浏览器状态栏。首次打开插件时，需要根据提示选择用于保存数据的本地文件夹。

## 🔒 隐私声明
本项目秉持数据隐私至上的原则。所有的集锦数据和备注信息**仅保存在您的本地设备中**，插件绝对不会收集或将任何数据上传至任何第三方服务器。
